# Eliq

> Eliq (Eliq AB, Gothenburg, Sweden) provides energy data and analytics APIs for utilities and
> energy-app developers. It ingests customer, location, meter and consumption data, then returns
> presentation-ready insights: consumption and cost aggregates, appliance-level disaggregation
> (NILM), forecasting, anomaly detection, peak power, tariff and day-ahead price comparison,
> similar-homes benchmarking, budgets and customer segmentation.

Generated by API Evangelist on 2026-09-06 from Eliq's own published contracts and documentation.
Eliq serves no /llms.txt of its own (probed developer.eliq.com/llms.txt and eliq.com/llms.txt,
both 404 on 2026-09-06).

Access model: commercial. A `client_id` is issued by an Eliq account manager; there is no
self-serve API key, no published pricing, and no free tier. The developer portal has a self-serve
signup that grants documentation access only, and the API Reference sits behind a separate
"request access" form. The four OpenAPI documents below are, however, served publicly and
anonymously.

## APIs

- [Eliq Auth API](https://developer.eliq.com/api-reference/auth-api): OAuth 2.0 client-credentials
  token service. Base https://auth-api.eliq.com (UAT: https://auth-api-uat.eliq.com). 3 operations.
- [Eliq Data Management API](https://developer.eliq.com/api-reference/data-mgmt-api): provision
  users, locations, profiles and meters; post energy readings and price formulas; run async bulk
  jobs. 78 operations. Base https://{tenant}.data-management-api.eliq.com/integration/api/v1
- [Eliq Insights API](https://developer.eliq.com/api-reference/insights-api): analytics for
  end-user energy apps — consumption, cost, CO2, EUC breakdown, similar homes, market price,
  forecast, anomalies, budgets, advice. 57 operations. Base https://{tenant}.insights-api.eliq.com
- [Eliq Intelligence API](https://developer.eliq.com/api-reference/intelligence-api): portfolio
  segmentation, filtering, mapping and export for utility service and growth teams. 10 operations.
  Access granted on request. Base https://{tenant}.intelligence-api.eliq.com

## What Eliq does NOT publish

Recorded so an agent does not go looking. As measured on 2026-09-06:
no MCP server, no A2A agent card, no llms.txt, no AsyncAPI document, no security.txt,
no /.well-known/api-catalog, no status page, no public SLA, no published pricing or plans,
no first-party SDK in any language registry, no CLI, no rate-limit response headers and no
documented 429, no Idempotency-Key header, no RFC 9457 problem+json, no dry-run mode.
